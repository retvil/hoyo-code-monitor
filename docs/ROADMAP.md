## Принципы (зафиксированы)

1. Локально-only: ничего не покидает ПК, кроме запросов к источникам и Hoyolab API.
2. Один шаг — один коммит, сразу после зелёных тестов (`docs/WORKFLOW.md`).
3. Никаких параллельных правок одних файлов.
4. Сначала живой пруф (сеть/API), потом коммит.
5. Безопасность: куки только в Fernet, секреты — никогда в git.
6. Сначала сверка с референсами (genshin.py/SIMNet/MihoyoBBSTools), потом код.
