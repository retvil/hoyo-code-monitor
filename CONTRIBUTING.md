# Contributing

## Workflow
1. Fork the repo
2. Create a feature branch (`git checkout -b feature/name`)
3. Commit your changes
4. Push and open a PR

## PR Checklist
- [ ] Tests pass
- [ ] Linter clean
- [ ] Changelog updated in `## [Unreleased]`
- [ ] README updated if user-facing changes

## i18n
Translations are in `docs/`. Keep structure identical to EN.
